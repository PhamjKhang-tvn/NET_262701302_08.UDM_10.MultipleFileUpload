# TV6 - Presentation, video and oral defense

## Suggested demo sequence
1. Show configuration and Start/Stop on Server GUI.
2. Demonstrate logs for connect, successful upload and controlled failure.
3. Open the teacher-format test case workbook and explain evidence recording.
4. Show measured tests and screenshots only after a real run; do not invent performance numbers.

## Questions to practice
### 1. What is the difference between a test case and a result?
A test case is a defined procedure and expected outcome; a result requires executing it and preserving evidence.

### 2. Can automated loopback tests replace LAN tests?
No. Loopback validates logic on one machine; LAN uses a real network path.

### 3. Why log events?
Logs help trace connect, disconnect, upload, error and timestamps for diagnosis.

### 4. What should be reported for load tests?
Environment, client count, file count/size, duration, throughput, memory, errors and evidence.

### 5. What do you do when a test fails?
Record actual behavior, issue and steps to reproduce; fix and rerun without rewriting history.

## Required recording and evidence
- Record the individual explaining THEIR component, including their face as required in the course.
- Use the actual running build, not a mocked successful result.
- Mention a limitation and a known failure case where appropriate.
- TV2 may combine members videos into a group video only AFTER receiving real recordings.
